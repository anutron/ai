## Writing style

- **Titles:** Always sentence case (capitalize first word only). Never Title Case or ALL CAPS.
- **Dashes:** Never use em-dash (—) in anything written to disk or drafted for someone else – files, commits, docs, emails, Slack messages, artifacts. Use en-dash (–) instead. No exceptions. Scan before writing/sending.
- Live conversational chat replies are exempt from the dash scan – don't re-read finished chat output solely to hunt for em-dashes.
