## Bash command style

Before running a bash command shaped like `cd <repo> && git ...`, `$(...)`/backticks/heredocs, inline `python3 -c`/`node -e`/`ruby -e`/`perl -e`, multi-line shell logic, or before allowlisting a new script path – always use the `bash-style` skill first.
